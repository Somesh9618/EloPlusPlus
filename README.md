# Elo++


Chess Analytics & Game Review Platform
Tech Stack: Python, Flask, JavaScript, REST APIs, CSS3


• This is a full-stack chess analytics dashboard integrating Chess.com 
  REST API to fetch and analyze player ratings, game archives, and 
  move-level data across Blitz, Rapid, and Bullet formats.

• Engineered parallel game archive fetching using ThreadPoolExecutor 
  and Flask-Caching, reducing data retrieval latency by 60%.

• Developed a client-side PGN game review engine with move quality 
  classification (Brilliant, Best, Mistake, Blunder), dynamic 
  advantage gauges, and keyboard-driven move navigation.

• Designed an algorithmic weakness-detection system providing 
  personalized improvement notes and curated YouTube training 
  resources based on loss pattern analysis.
